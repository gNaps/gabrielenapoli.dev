## 🌍 Web development and software development: neighboring galaxies, with differences
<br />
Let us start with an important distinction. "Software development" covers the whole universe of creating programs: smartphone apps, video games, business management systems, operating systems.
<br />
**Web development** is a specific constellation within this universe: applications accessible over the internet through a browser such as Chrome, Firefox or Safari. In practice, anything you can open by typing an address into your browser was most likely built by a web developer.
<br />
The fundamental difference is in the *where* and *how*:
<br />
- **Where it runs**: a desktop app lives on your computer, a mobile app on your phone. A web app lives *on the web*: hosted on a server and executed, at least partly, by the user's browser.
- **Which languages it uses**: general software speaks Java, C#, C++ and Swift; the web speaks HTML, CSS and JavaScript, plus server-side languages.
- **What it produces**: programs you install on one side, applications reachable through a simple address on the other.
- **How it reaches users**: no installation or manual updates; publish to the server, and everyone has the latest version.
<br />
This changes how you think: you work with technologies designed for networks, account for different devices and browsers, use protocols such as HTTP, and whenever you write code, ask what happens between **client and server**. We will return to that very soon.
<br />
## 🧠 Why do web apps exist?
<br />
Simply put: **to help people do things**. Read email, buy clothes, book an appointment, collaborate on a document. Every web app has a specific purpose: making tools, information or services easy to access wherever there is a connection.
<br />
Think about it. Every time you open **Gmail**, you use a web app to communicate. When you listen to music on **Spotify Web**, you interact with an interface built to handle streaming, playlists and recommendations. When you buy something on **Amazon**, you enter a complex machine of interfaces, backend logic, order management and payments.
<br />
Behind all of this is a team of web developers who conceived, designed and built every click, button and piece of data you see.
<br />
## 🧑‍💻 So... what does a web developer do?
<br />
If you wonder what role you could play, the answer is: **one of the protagonists**. A web developer builds these experiences, translating ideas into interfaces, flows and code.
<br />
Be aware, though: "web developer" is a broad term covering different roles, sometimes with highly specialized skills.
<br />
- A **frontend developer** handles everything users see and touch: HTML, CSS, JavaScript, interfaces, animations.
- A **backend developer** works on the invisible but essential side: application logic, APIs, databases, security.
- A **full stack developer** moves comfortably on both fronts, like a true galactic explorer.
<br />
Day to day, a web developer writes code, tests features, works alongside designers and product managers, attends meetings (often too many), releases versions, hunts bugs and sometimes performs magic, or at least tries. The goal stays the same: **building functional, fast, accessible and secure web experiences**.

> Do not let the choice between frontend, backend and full stack intimidate you: you need not decide today. At the beginning, explore everything; your direction will emerge along the way.
