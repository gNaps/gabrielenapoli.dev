**NapSQL** is a cross-platform desktop SQL client for Microsoft SQL Server, built
as a lighter, more modern alternative to SQL Server Management Studio.

<br />
It's built with React and Electron, so it runs natively on Windows, macOS and
Linux.

<br />
### My role
<br />
I built NapSQL from the ground up — the Electron shell, the React interface and
the integration with SQL Server — aiming for a fast, modern client that stays out
of your way.
