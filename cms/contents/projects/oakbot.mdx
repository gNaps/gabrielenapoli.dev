**OakBot** is a Telegram bot that gives Pokémon fans quick, interactive access
to game data through simple chat commands — stats, type matchups and evolutions,
returned in seconds.

<br />
It's built in Node.js with the grammY framework and connects to a GraphQL Pokémon
API, turning structured data into a conversational experience.

<br />
### What it does
<br />

- Pokémon insights: `/stats pikachu` returns base stats, abilities, evolutions and moves.
- Type matchups: `/type gengar` breaks down strengths and weaknesses by type combination.
- Evolution chains: `/evo eevee` shows the full evolution tree, including conditions.

<br />
